# Smart Recycle System - Frontend

The frontend for the Smart Recycle System, a modern, responsive web application designed to help users identify recyclable waste and get creative reuse ideas. Built with React, Vite, and Tailwind CSS.

## 🚀 Technologies

- **React 19**: UI Library
- **Vite**: Build tool and bundler
- **Tailwind CSS 4**: Utility-first CSS framework
- **Framer Motion**: Animations and transitions
- **Lucide React**: Icons
- **Axios**: HTTP Client

## 📦 Installation

1.  Navigate to the frontend directory:
    ```bash
    cd frontend
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

## 🔧 Configuration

The frontend communicates with the backend server. By default, it expects the backend to be running at `http://localhost:4000`.

To change this, update `src/pages/RecycleAssessment.jsx` (or the environment configuration if available).

## ✨ Features

- **Waste Analysis**: Upload images of waste items for instant AI analysis.
- **Smart Recommendations**: Get tailored DIY reuse ideas and recycling instructions.
- **Theme Support**: Dark and Light mode toggle.
- **Responsive Design**: Optimized for all devices (Mobile, Tablet, Desktop).
